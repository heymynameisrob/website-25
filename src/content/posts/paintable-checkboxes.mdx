Nothing feels more daunting than having a big list of you have to go through. Often these items are represented as Checkboxes. The simple UI affordance that tells you if it's on/off can be annoying when you have lots of items to select.

But what if you could 'paint' them instead?

Hold Shift and drag your pointer to select nearby options. I struggled to find many examples of this in the wild, except Linear.

First, we must distinguish a normal click from a Shift-drag. The pointer-down handler only starts painting when the event reports that Shift is pressed.

```ts title="useCheckboxPaint.ts"
if (!event.shiftKey) return;
```

A normal click still reaches the checkbox and toggles it. If the user starts painting, we also track where they started, where they moved, and what was checked before the drag.

We can store this transient interaction state in `useRef`.

```ts title="useCheckboxPaint.ts"
const rootIndexRef = React.useRef<number | null>(null);
const currentIndexRef = React.useRef<number | null>(null);
const checkedBeforeDragRef = React.useRef<Set<string>>(new Set());
const isDragStarted = React.useRef(false);
const didDragRef = React.useRef(false);
```

`useRef` stores these values without triggering a re-render when they change, unlike `useState`. These values do not directly affect the UI, so they do not need to trigger a render.

We also need to understand the range of checkboxes you dragged over. Once we have those, we can find those elements and 'check' them.

```ts title="useCheckboxPaint.ts"
function updatePaintedRange(currentIndex: number) {
  const rootIndex = rootIndexRef.current;
  if (rootIndex === null) return;

  const next = new Set(checkedBeforeDragRef.current);
  const range = getRange(rootIndex, currentIndex);

  for (const value of range) {
    next.add(value);
  }

  setChecked([...next]);
  currentIndexRef.current = currentIndex;
}
```

The `getRange` function gives us all the elements inbetween the starting point and where we are so we can check them accordingly.

When setting the range, we always start with the items that were checked before the drag. Each pointer move rebuilds the range from that fixed snapshot.
